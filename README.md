# Craps Lab Field Guide

The player's guide for **Craps Lab**, an Android craps simulator and strategy
tester by EmptySea. Served by GitHub Pages at:

**https://mtc8.github.io/craps-lab-guide/**

The app's **?** button opens this page, and it is the support URL on the Play
listing.

## Craps Lab is a simulation

No real money, no deposits, no prizes, no cashing out. The bankroll on screen is
a number that resets when you start a new game. Practice or success in the app
does not imply future success at real-money gambling.

## This repository is generated

Do not edit `index.html` here — it is built from the source in the private
project repo and any change made here is lost on the next publish. The source is
`CrapsStore/tutorial/tutorial.src.html`, and `_publish-to-pages.ps1` builds this
directory from it.

The screenshots come from a scripted capture pass against a real build, so the
guide always shows the app as it actually is rather than as it was staged.
